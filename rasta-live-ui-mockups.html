During run — Paint canvas (Destination)

Reached by clicking Edit on the Destination or Best-output tab in the dashboard. No off-the-shelf ImGui+SDL3 paint widget covers this (imgui-paint exists but renders through NanoVG — a second rendering backend we don't need; imgui_canvas is a bare shape/masking primitive, not a tool palette) — proposal below is a small custom layer: plain ImDrawList for the toolbar/cursor, a CPU pixel buffer for the canvas (these images top out around 320×240, so Bresenham lines / flood fill / midpoint circles are trivial at this scale), uploaded to the existing SDL_Texture only on stroke-end.

edit mode

During run — Painting the details mask

The other half of paint mode, and the half worth building first. Reached from Overlay ▸ ✎Edit on the dashboard whether or not a mask file was chosen in Setup — the run always owns a mask layer, and an unpainted one is all zeroes, which in legacy mode weighs exactly 1.0 everywhere and so is bit-identical to having no mask at all. The brush paints priority, so there is no colour picker and no palette: a 0–1 strength ramp replaces them, and the eyedropper is hidden rather than disabled. Strokes apply on release — no Apply button — because the rebuild is confined to the pixels the stroke covered.

▾Snapshots

＋ Save snapshot now

Taken automatically before the first stroke after a save, so painting is never destructive. The painted mask itself is saved with the run as OUTPUT-details.png and the recorded command line is rewritten to point at it — which is what makes Continue, Reuse and Recent still mean something once a run has been painted.

Undo vs. Snapshot — two different safety nets

Undo (Ctrl+Z, toolbar buttons) is per-stroke and scoped to the canvas being edited — cheap, since a full 320×240 buffer copy is ~230 KB, so snapshotting the whole buffer before each stroke (rather than diffing) is simplest and still trivial at this resolution. Snapshot is a manual, named restore point spanning the entire conversion state — destination, mask, objective weights, and the current best raster program — reusing the checkpoint format that already backs /resume. Undo protects a brush stroke; Snapshot protects a session.

What stays exactly as-is

Nogui/console builds, gui.h's four-primitive contract, and the existing keyboard shortcuts (A/B/M, S/D, Esc) are untouched — the mockups above are what /livegui adds on top, not a replacement path.

Smallest slice to prototype first

The Live Tuning panel on screen 2 (details floor/strength only) exercises the full new mechanism — ImGui event routing, the LiveTunables atomics, mask-preview regen — in isolation, before building the full setup screen around it.
